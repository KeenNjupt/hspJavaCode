1. 备份mysql数据库命令
dos下执行
mysqldump  -u root -p -B 数据库名 > 文件路径
恢复数据库，命令行下执行
mysql -u root -p -e "source 文件路径"

备份指定库中的指定表
mysqldump -u root -p 数据库名 表1 表2 > 文件路径

2. 创建表
CREATE TABLE table_name
(
    field1 datatype,
    field2 datatype,
    field3 datatype
)
character set 字符集 collate 校对规则 engine 存储引擎
field为列名、datatype为列类型
character set: 不指定时，默认为数据库字符集
collate: 不指定时，默认为数据库校对规则
utf8_general_ci 表示不区分大小写(case ignore)、utf8_bin表示按照二进制进行比较,区分大小写(binary)

3. mysql数据类型
位类型: BIT(M) M指定位数 1-64
整型: tinyint(1字节)、smallint(2字节)、mediumint(3字节)、int(4字节)、bigint(8字节)
小数类型: float(4字节)、double(8字节)、decimal(M,D)(M表示总位数，D表示小数位数，大小根据M和D的取值确定)
字符串类型: char(0-255 )、varchar(0-65535 )、text(0-65535 2字节)、longtext(0-2^32-1 4字节)
二进制数据：blob(0-65535 2字节)、longblob(0-2^32-1 4字节)
日期类型：date(年-月-日)、time(时分秒)、datetime(年月日时分秒 YYYY-MM-DD HH:mm:SS)、timestamp(时间戳)

4.测试数据类型
tinyint有符号范围-128 - 127 , 无符号范围：0-255, 字段类型后不加unsigned时，默认为有符号
向该字段中插入值-129会报错

bit(m) m表示位数，如bit(8)表示可存储8位，即0-255
插入和筛选时可使用十进制值插入和筛选
查询时，展示为二进制数据
使用命令行查询时，bit位默认转为ascii码字符显示，如要显示为二进制使用命令 select bin(bit_num) from table
如要显示为十进制：select bit_num+0 from table

小数类型
decimal(m,d) m默认为10， d默认为0， m最大为65， d最大为30

字符串类型
char(size) 固定长度字符串，size为字符数，最大255
varchar(size) 可变长度字符串，size为字符数，但varchar理论最大可使用的字节为65535，但是实际使用时有三个字节用于记录大小
实际可用的字符数，与编码格式有关，utf8一个字符占用三个字节，则可用字符数为(65535-2)/3 = 21844
gbk一个字符占用两个字节，则可用字符数为(65535-2)/2 = 32766
char(4)和varchar(4)都表示可存放4个字符，与编码方式无关
char(4)表示该字段占用的空间是确定的：4个字符，加入插入值为'aa',但实际仍会分配4个字符的空间
varchar(4)表示该字段占用的空间是可变的，最大为4个字符，加入插入值为'aa',则实际占用的空间为:2个字符空间+(1-3)字节用来记录内容长度的变量
char因为是定长的，查询较快，使用用字段值长度确定的情况，如身份证号

日期类型
timestamp 设置为default current_timestamp on update current_timestamp
表示默认为当前时间的时间戳，更新时也默认为当前时间的时间戳
